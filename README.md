# Smart-Remote

ESP32 based universal IR Remote

Current Progress:
- LG NEC IR control
- Roku IR control
- Basic Screen control

Goals:
- Control any IR TV
- Allow custom IR programming
- Host custom webpage to update/configure
- Add bluetooth/RF control?

Components:
- ESP32-S3
- IR LED
- IR Receiver
- OLED Screen
- NPN Transistor
